# 03. 의사결정 · 미해결 사항 — 폴더 안내

| 항목 | 내용 |
| --- | --- |
| 문서 그룹 | `DCS` |
| 목적 | **왜 그렇게 정했는가**와 **아직 못 정한 것**을 관리한다 |
| 최종 수정 | 2026-08-28 |

> 전체 문서 지도는 [`_docs/README.md`](../README.md) 에 있습니다.

---

## 문서 목록

| 문서 ID | 문서 | 다루는 내용 |
| --- | --- | --- |
| DCS-01 | [의사결정 기록](01_의사결정_기록.md) | 확정된 결정 `DEC-001~011`, 의도적으로 하지 않기로 한 것 |
| DCS-02 | [미해결 사항](02_미해결사항.md) | 열린 이슈 `OPEN-002~014`, 해결 절차, 논리 검토가 필요한 지점 |

---

## 이 폴더를 쓰는 방식

```mermaid
flowchart LR
    Q["논리적으로 맞지 않거나<br/>정하지 못한 것 발견"] --> O["DCS-02 에 OPEN-0NN 등록<br/>담당·시점 지정"]
    O --> R["담당자가 근거 정리 → 팀 합의"]
    R --> D["DCS-01 에 DEC-0NN 등록"]
    D --> M["DCS-02 해결된 항목으로 이동"]
    M --> U["참조하던 문서 갱신 + 메모리 기록"]
```

| 상황 | 할 일 |
| --- | --- |
| 기술 선택을 했다 | `DCS-01` 에 `DEC-0NN` 추가 (결정/검토안/근거/영향/결정일) |
| 결정을 뒤집는다 | 기존 항목을 지우지 말고 **폐기 표시** 후 새 번호로 등록 |
| 정할 수 없다 | `DCS-02` 에 `OPEN-0NN` 추가. 다른 문서에는 `TBD` 대신 이 ID를 쓴다 |
| 문서끼리 모순을 발견했다 | `DCS-02` 의 **2.4 논리 검토가 필요한 지점** 에 적고, 심각하면 `OPEN` 으로 승격 |

---

## 다른 문서에서의 참조 규칙

- 결정 내용을 **복사하지 않습니다.** `DEC-004` 처럼 ID만 적습니다.
- 미정 사항은 **`TBD` 라고 쓰지 않습니다.** `OPEN-005` 처럼 ID를 적습니다.
- 그래야 결정이 바뀔 때 **이 폴더 한 곳만** 고치면 됩니다.
