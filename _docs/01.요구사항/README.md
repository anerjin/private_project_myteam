## 이 폴더의 규칙

| 규칙 | 설명 |
| --- | --- |
| 다루는 것 | 사용자가 무엇을 할 수 있어야 하는가, 어떤 제약을 지켜야 하는가 |
| 다루지 않는 것 | 테이블·API·폴더 구조·화면 구현 — 전부 `02.개발설계` 소관 |
| 요구사항 ID | `FR-<도메인>-<3자리>` / `NFR-<분류>-<3자리>` — 한 번 부여하면 재사용하지 않는다 |
| 우선순위 | `P0` MVP 필수 / `P1` 1차 확장 / `P2` 추후 |
| 변경 시 | 문서 하단 변경 이력에 기록하고, 결정이 바뀌었다면 `DCS-01` 도 함께 갱신한다 |
| 하위 폴더 | 만들지 않는다. 뷰어가 한 겹만 스캔한다 |
