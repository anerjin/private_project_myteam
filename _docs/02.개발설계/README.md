## 코드를 쓰기 전에 확인할 것

- [ ] 이 작업이 어떤 `FR-*` / `NFR-*` 를 만족시키는지 안다
- [ ] [DEV-06 폴더 구조 규약](06_폴더_구조_규약.md)의 배치 결정 트리를 따랐다
- [ ] Server Action이라면 [DEV-05 · 5.10절](05_API_설계.md)의 **6단계 순서**를 지켰다
- [ ] 자료를 만들거나 고치는 로직이면 **웹과 CLI가 같은 service 를 지나는지** 확인했다 (`NFR-SEC-018`)
- [ ] 스키마를 바꿨다면 마이그레이션 파일을 PR에 포함했다
- [ ] 권한이 관련되면 [REQ-02 권한 매트릭스](../01.요구사항/02_사용자_권한_정책.md)를 갱신했다
- [ ] 설계 판단을 바꿨다면 [DCS-01 의사결정 기록](../03.의사결정_및_미해결사항/01_의사결정_기록.md)에 남겼다

## 이 폴더의 규칙

| 규칙 | 설명 |
| --- | --- |
| 다루는 것 | 아키텍처, 데이터, 화면, API, 폴더 구조, 일정 |
| 다루지 않는 것 | "무엇이 필요한가" — 그건 `01.요구사항` |
| 결정 근거 | 여기에 길게 적지 않고 `DCS-01` 에 `DEC-0NN` 으로 남긴 뒤 참조한다 |
| 코드 예시 | 실제 구현과 어긋나면 문서를 고친다. 어긋난 예시는 없느니만 못하다 |
| 하위 폴더 | 만들지 않는다. 뷰어가 한 겹만 스캔한다 |
